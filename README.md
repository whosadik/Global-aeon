# 🌐 Global Aeon – Corporate Landing Concept

This is the **hero section** of a corporate website built for **Global Aeon** during my internship.  
It features a **high-quality animated video logo** created in **Adobe After Effects**, embedded into a clean React layout.

📌 [Live Demo (optional)] https://whosadik.github.io/Global-aeon/

---

## 🎯 Project Highlights
- 🎞️ Animated video logo rendered from **After Effects**
- ✨ Sleek, modern corporate design with clean spacing
- 📱 Fully responsive hero section (mobile-first)
- 🧭 Top navigation: Works · Services · About · Contacts
- ⚛️ Built with **React** and custom **CSS**

---

## 🛠 Tech Stack
- React
- CSS (no framework)
- Adobe After Effects (logo animation)
- HTML5 `<video>` integration

---

## 👨‍💻 About the Project

This was a real-world internship project for **Global Aeon**, where I worked as a **frontend developer**.  
My responsibilities included:
- Designing and animating the official logo using After Effects  
- Exporting and embedding the animation as a high-quality video  
- Implementing a responsive and minimalist layout with React  
- Laying the foundation for a full corporate website

---

## 🚧 Status
✅ MVP: Hero section with animation  
🔜 Planned: Full pages for Services, About, and Contact  
🛠️ In progress: Reusable components and interaction logic
